# SIP-AAC Dayan Dawood USK — Frontend

Frontend **SIP-AAC Dayan Dawood** untuk informasi, tarif, kalender, dan pengajuan pemesanan Gedung AAC USK.

> **Catatan implementasi:** saat ini proyek hanya mencakup frontend. Data booking contoh berada di memori browser; autentikasi pengelola, penyimpanan permanen, dan unggah berkas sungguhan belum terhubung. Integrasikan backend sebelum menerima pengajuan publik.

## Struktur Folder
- `index.html` — Halaman utama aplikasi.
- `css/style.css` — Gaya visual aplikasi.
- `js/tailwind.config.js` — Konfigurasi tema Tailwind CSS.
- `js/data.js` — Data zona, tarif, dan booking awal.
- `js/app.js` — Logika interaktif aplikasi.
- `assets/` — Foto Gedung AAC dan dokumentasi kegiatan wisuda untuk halaman beranda.
- `usk-icon.png` — Lambang Universitas Syiah Kuala yang digunakan pada identitas aplikasi.
- `README.md` — Panduan membuka dan menjalankan proyek di VS Code.

## Cara Menjalankan di VS Code
1. Ekstrak file ZIP ini ke folder kerja Anda.
2. Buka **VS Code** -> pilih **File > Open Folder...** -> pilih folder `sip-aac-dayan-dawood-usk`.
3. Klik kanan pada file `index.html`, lalu pilih **Open with Live Server** (atau buka `index.html` langsung di browser).
